# Ballast

A portfolio backtester and glidepath lab for Windows. Test how leveraged and defensive portfolios would have
behaved through past booms and recessions, switch between risk-on (Type A) and defensive (Type B) portfolios,
include real US capital gains tax, and see forecast ranges from your own backtests.

## Install

1. Open the [latest release](../../releases/latest) and download **`Ballast-Setup-x.y.z.zip`** (about 180 MB).
2. Unzip it, open the `Ballast` folder and double-click **`Install Ballast.bat`**.
   - If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
3. Open Ballast from the icon on your desktop and create a free account (you'll get a 6-digit code by email).

Updates install from inside the app. Your portfolios and results stay on your own PC.

## Requirements

Windows 10 or 11 (64-bit). The optional AI assistant runs locally with Ollama and works best with an NVIDIA GPU.
