# Ballast

A portfolio backtester and glidepath lab for Windows. Test how leveraged and defensive portfolios would have
behaved through past booms and recessions, switch between risk-on (Type A) and defensive (Type B) portfolios,
include real US capital gains tax, and see forecast ranges from your own backtests.

**Website:** https://eluder01.github.io/Ballast-releases/

## Install

1. Open the [latest release](../../releases/latest) and download **`Ballast-Setup-x.y.z.exe`**.
2. Run it and follow the setup wizard. No administrator rights are needed.
   - If Windows shows *"Windows protected your PC"*, click **More info → Run anyway** (Ballast isn't code-signed yet).
3. Open Ballast from the Start menu or your desktop, then sign in with Google or create a free account.

Updates install from inside the app. Your portfolios and results stay on your own PC. Uninstall from
**Settings → Apps** at any time; your data is kept unless you delete `%APPDATA%\Ballast`.

## Requirements

Windows 10 or 11 (64-bit). The optional AI assistant runs locally with [Ollama](https://ollama.com) (works best with an
NVIDIA GPU) or with your own Gemini API key.
